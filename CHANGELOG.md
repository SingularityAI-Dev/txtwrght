- 2026-09-16: Added a second test suite: 46 Node tests running the `dom/*.js` payloads against happy-dom with no browser, in ~2.5s (`npm test`). Covers what the Playwright suite never asserted directly, including that the click-delivery listener survives a page calling `stopPropagation` (it listens in the capture phase, and a bubble-phase listener would have made a real click look undelivered and triggered a redundant second dispatch), that an explicit `pixels: 0` scrolls zero rather than a full page (`??` not `||`), and that `domQuiet` disconnects its observer on both the quiet and the cap path. Python suite 92 -> 94, both new. README documents the payload layout and why there are two suites; the hero banner's chip was re-measured in a browser rather than nudged, since the text grew by one character.
- 2026-09-04: Scoped V2 (local-environment CLI + Chrome extension) into a local, gitignored `DEVELOPMENT_PLAN_V2.md`. Planning surfaced four defects in shipped code, all confirmed by reading rather than assumed: `session.py:116`'s `_process_alive` calls `os.kill(pid, 0)`, which on Windows invokes `TerminateProcess`, so the liveness check would kill the browser it is checking on (plus `start_new_session=True` and `os.killpg`/`os.getpgid`, none of which exist off POSIX); `trace.py:33-35` creates a `traces/` directory as a construction side effect in whatever cwd it is called from; `session.py` hardcodes `Path("traces")` at two sites rather than sharing one; and `tools.select_dropdown_option` is the only action verb with no fallback path. Also measured, not assumed: Ollama's OpenAI-compat endpoint lists `tool_choice` as unsupported, and `llm.py:319` sends a forced one, which is the actual reason a local model fails here (`normalize_response` already tolerates prose-wrapped JSON, so the fix is request-side). Extension architecture decided as a transport bridge shipping `extractor.js` verbatim with serialization staying in Python, rather than a self-contained MV3 agent that would fork the serialized-page prompt contract into an untested second implementation and forfeit `distill`.
